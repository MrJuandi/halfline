# Halfline · web

Frontend de Halfline: React 19, TypeScript, Vite y Tailwind 4. Lee los datos de la API Python (`python -m futdata.api`, puerto 8000).

```bash
npm install
npm run dev     # http://localhost:5173
npm run build
```

El sistema visual está en `src/index.css` y la guía de diseño en `../docs/design/research.md`.
